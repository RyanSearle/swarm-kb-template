# Code of Conduct

This project follows the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment of any kind.
Report unacceptable behavior to the maintainer via GitHub
([@RyanSearle](https://github.com/RyanSearle)). Reports are handled
confidentially; the maintainer may warn, temporarily restrict, or ban
participants whose behavior violates the covenant.
